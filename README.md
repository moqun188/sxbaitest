# 听写词语学习系统 (sxbaitest)

## 📋 产品需求文档 (PRD)

### 1. 产品概述
一款面向小学生的语文听写词语辅助学习工具。通过扫描课本页面提取词语，以随机朗读的方式进行听写测试，再通过扫描学生手写内容进行自动比对纠错，帮助学生高效巩固词语记忆。

### 2. 核心功能

| 序号 | 功能模块 | 描述 |
|------|---------|------|
| F1 | 课本扫描识别 | 扫描课本页面，OCR提取词语列表 |
| F2 | 词语记忆存储 | 将识别的词语存入词库，支持按课/单元管理 |
| F3 | 随机听写朗读 | 随机读出词语，朗读间隔时间可配置（默认3秒） |
| F4 | 手写扫描识别 | 扫描学生背写的词语，OCR识别手写内容 |
| F5 | 智能比对纠错 | 将手写内容与原文逐词比对，标注正确/错误 |
| F6 | 错词记录管理 | 记录听写错误的词语，支持复习和统计 |

### 3. 用户故事

```
作为一个 [小学生家长]
我想要 [扫描课本获取词语列表并自动听写]
以便 [孩子能独立完成词语听写练习，减轻家长陪读负担]

作为一个 [学生]
我想要 [听写后扫描我的手写，自动知道哪些写错了]
以便 [针对性地复习错误词语，提高学习效率]
```

### 4. 技术架构

```
┌─────────────────────────────────────────┐
│              前端 (Web UI)               │
│  扫描上传 │ 听写界面 │ 结果展示 │ 错词本  │
├─────────────────────────────────────────┤
│              后端 API (Node.js)          │
│  OCR识别  │ 词语管理 │ 朗读引擎 │ 比对引擎│
├─────────────────────────────────────────┤
│              数据层 (SQLite)             │
│  词语库  │  听写记录 │  错词库  │ 用户配置 │
└─────────────────────────────────────────┘
```

### 5. 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `readInterval` | 3000ms | 每个词语朗读间隔 |
| `readRepeat` | 2 | 每个词语朗读次数 |
| `readSpeed` | normal | 朗读速度 (slow/normal/fast) |
| `ocrLanguage` | chi_sim | OCR识别语言 |
| `matchThreshold` | 0.8 | 比对相似度阈值 |

### 6. 非功能需求
- 支持离线使用（本地OCR + SQLite）
- 响应时间 < 2s（OCR识别）
- 支持移动端拍照上传
- 数据本地存储，保护隐私
